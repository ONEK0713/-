## 1. 背景与目标

### 1.1 背景

本地音乐文件散落在多个文件夹中，主流播放器普遍存在体积大、广告多、强制登录、依赖在线曲库的问题。用户需要一个"只播放我自己的文件"的轻量工具。

### 1.2 产品目标

做一个**纯本地、免登录、离线可用**的音乐播放器：打开即可播放，关闭后能接着上次继续。

### 1.3 成功标准（MVP）

- 新用户从打开到播放第一首歌 ≤ 1 分钟
- 重启后可恢复上次曲目与进度
- 1000 首曲库下列表与播放保持流畅
- 断网状态下功能完整可用
- 播放时能同步显示歌词（存在歌词数据时）

### 1.4 非目标

不做在线曲库、账号体系、云同步、社交分享、多端同步。

## 2. 目标用户与场景

**目标用户**：拥有个人本地音乐收藏（MP3 / FLAC 等），希望轻量播放、不想被账号和广告打扰的用户。

**典型场景**：

1. 工作或写代码时随机播放背景音乐
2. 按专辑顺序完整聆听
3. 想听某首歌时快速搜索并播放
4. 关闭后第二天打开，继续上次进度

## 3. 产品定位

> 一个不需要登录、不联网、打开就能听本地音乐的播放器。

**形态**：本地 Web 应用（Vite + React + TypeScript），在浏览器中运行；后续可封装为桌面应用。

## 4. MVP 范围

### 4.1 P0 必须做

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 导入 | 文件夹 / 文件导入 | 递归扫描、标签解析、增量更新 |
| 曲库 | 列表、搜索、排序 | 标题 / 歌手 / 专辑 / 时长 |
| 播放 | 基础控制 | 播放暂停、上下曲、进度、音量、静音 |
| 队列 | 播放队列与模式 | 顺序 / 列表循环 / 单曲循环 / 随机 |
| 状态 | 记忆与恢复 | 音量、模式、上次曲目与进度、曲库目录 |
| 歌词 | 读取与同步显示 | 同名 .lrc 优先，内嵌歌词兜底 |
| 体验 | 快捷键与状态反馈 | 空格、方向键、空态 / 加载 / 错误 |

### 4.2 P1 后续版本

- 自建歌单（新建、重命名、拖拽排序、m3u 导入导出）
- 播放历史与"最近添加"
- 歌词偏移校准
- 系统集成：Media Session、托盘、迷你窗
- 收藏 / 喜欢

### 4.3 明确不做

账号体系、云同步、在线流媒体、社交分享、音效 / EQ、主题皮肤、多端同步、逐字歌词、MV、播客。

理由：每一项都能独立吃掉一周以上，且不解决"能不能好好听歌"。

## 5. 核心流程

1. 首次打开 → 空态引导 → 选择音乐文件夹
2. 扫描并解析 → 曲库列表出现
3. 点击歌曲 → 加入队列并播放
4. 播放中：暂停、切歌、拖进度、调音量、切模式
5. 关闭 → 下次打开恢复曲库、曲目与进度

## 6. 功能说明

### 6.1 曲库导入

- **入口**：空态主按钮"选择音乐文件夹"；顶部"导入"支持补充文件夹或单个文件
- **行为**：递归扫描子目录；识别 mp3 / flac / m4a / aac / wav / ogg；解析标题、歌手、专辑、封面、时长；同时查找同名 `.lrc` 与内嵌歌词；缺失时用文件名兜底
- **增量**：记录文件路径 + 修改时间 + 大小，未变化则复用缓存
- **反馈**：展示扫描进度与数量；扫描过程中可继续浏览已有曲库
- **边界**：无权限、空文件夹、非音频文件、解析失败 → 跳过并汇总提示

### 6.2 曲库浏览与搜索

- **列表字段**：标题、歌手、专辑、时长；封面在播放条展示
- **排序**：默认按导入顺序；支持按标题 / 歌手 / 专辑排序
- **搜索**：即时过滤，匹配标题 / 歌手 / 专辑，忽略大小写
- **规模**：1000 首以上使用虚拟列表
- **操作**：单击播放并选中；选中行高亮

### 6.3 播放控制

- 播放 / 暂停、上一首 / 下一首
- 进度条：显示当前时长与总时长，可拖拽 seek
- 音量：滑块 + 静音切换，记忆音量
- 错误：解码失败提示并自动跳下一首，不中断队列
- 自动播放：受浏览器策略限制，首次播放需用户交互

### 6.4 队列与播放模式

- **队列生成**：点击歌曲时以当前列表为上下文，从该曲开始入队；"播放全部"从第一首开始
- **模式**：
  - 顺序播放：播到队尾停止
  - 列表循环：播到队尾回到队首
  - 单曲循环：当前曲循环
  - 随机：打乱剩余队列，一轮结束后重新洗牌
- **队列抽屉**：查看队列、跳到某曲、移除、清空

### 6.5 歌词

- **来源**（按优先级）：
  1. 音频同目录、同名的 `.lrc` 文件（`song.flac` → `song.lrc`）
  2. 音频内嵌歌词标签（ID3 `USLT`、FLAC `LYRICS` / `UNSYNCEDLYRICS`）
- **解析**：支持 `[mm:ss.xx]` 与 `[mm:ss:xx]`、一行多时间戳、`[offset:]` 偏移、`[ti:]` 等元信息；无法识别时间轴时按纯文本处理
- **编码**：优先 UTF-8（含 BOM），失败回退 GB18030，兼容常见的 GBK 歌词文件
- **读取时机**：导入时随标签一并解析并缓存；切歌时优先读缓存，未命中再读文件
- **展示**：有歌词时在右侧面板显示，当前行高亮并自动滚动居中；点击任意行跳转到对应时间
- **降级**：无时间轴只静态展示；无歌词显示"暂无歌词"，不打断播放
- **不做**：在线歌词匹配、逐字歌词（KTV 模式）、歌词编辑

### 6.6 状态记忆

- **保存内容**：音量、播放模式、当前曲目、播放进度、曲库目录句柄
- **时机**：进度每 5 秒节流保存 + 页面隐藏 / 关闭时保存
- **恢复**：启动时恢复曲库；若上次文件不可用，回到列表并提示，不静默失败

### 6.7 快捷键

| 按键 | 行为 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 5 秒 |
| Ctrl + ← / → | 上一首 / 下一首 |
| ↑ / ↓ | 音量 ±5% |
| M | 静音切换 |
| / | 聚焦搜索框 |

### 6.8 状态与反馈

- **空态**：引导导入音乐文件夹
- **加载态**：扫描与解析进度
- **错误态**：文件损坏、权限失效、目录不存在
- **离线**：无网络不影响任何功能

## 7. 界面结构

单页三区：左侧主区（搜索 + 曲库列表）、右侧歌词面板（可收起）、底部播放条。队列做成播放条上的抽屉，不单独占页面。

```
┌──────────────────────────────────────────────────┐
│ 🔍 搜索                              [ 导入 ]     │
│ ──────────────────────────────────────────────── │
│ 曲库列表                            │ 歌词        │
│  标题   歌手   专辑   时长           │  ……          │
│  ...                                │ ▶ 当前行      │
│  ...                                │  ……          │
├──────────────────────────────────────────────────┤
│ [封面] 歌名 · 歌手  ⏮ ⏯ ⏭  ──●── 2:31/4:05      │
│                          🔊  🔁  📄  ☰ 队列      │
└──────────────────────────────────────────────────┘
```

**简洁原则**：

- 一屏完成导入、搜索、播放、看歌词，不做页面跳转
- 歌词面板一键收起，不遮挡播放条；无歌词时显示轻量占位
- 播放条信息克制：封面、标题、歌手、必要控件
- MVP 不引入多级菜单和弹窗式设置

## 8. 非功能需求

- **性能**：列表滚动 60fps；本地切歌 < 100ms；缓存命中时首屏 < 1s；歌词滚动独立渲染，不触发列表重绘
- **兼容**：Chrome / Edge 最近两个大版本；Firefox / Safari 降级为拖拽导入（无目录持久化）
- **隐私**：不上传文件与元数据，无遥测，无账号
- **离线**：完全离线可用
- **可访问性**：键盘可完成主要操作，焦点可见
- **数据**：清空曲库仅删除本地缓存，不触碰源文件

## 9. 技术方案概要

- **前端**：Vite + React + TypeScript；Zustand 管理曲库与播放状态
- **音频**：HTMLAudioElement；后续需要 EQ / 交叉淡入淡出再引入 Web Audio
- **元数据**：music-metadata-browser
- **歌词**：自研 LRC 解析器（纯函数、可单测）；编码 UTF-8 → GB18030 回退；解析结果随曲库缓存存入 IndexedDB
- **目录访问**：File System Access API，目录句柄持久化到 IndexedDB；权限失效时引导重新授权
- **存储**：IndexedDB 存曲库缓存与句柄；localStorage 存轻量设置
- **测试**：Vitest + Testing Library，重点覆盖队列、随机、循环、记忆恢复、歌词解析等纯逻辑
- **运行**：本地静态服务（localhost，满足 File System Access 的安全上下文要求）

## 11. 验收标准

- [ ] 选择文件夹后能扫描出歌曲并显示正确标签
- [ ] 点击任意歌曲能立即播放，暂停 / 切歌 / 拖进度 / 调音量正常
- [ ] 四种播放模式行为正确
- [ ] 同名 `.lrc` 能随歌曲加载，按进度高亮滚动，点击行可跳转
- [ ] 无歌词、无时间轴或编码异常时降级展示，不报错
- [ ] 刷新或重启后恢复曲库、曲目与进度
- [ ] 1000 首列表滚动流畅
- [ ] 损坏文件被跳过并提示，不崩溃

## 12. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| File System Access 仅 Chromium 支持 | 其他浏览器不可用 | 拖拽导入降级；文档注明推荐浏览器 |
| 首次扫描慢 | 体验差 | 增量扫描 + 缓存 + 进度反馈 |
| 标签缺失或乱码 | 信息错误 | 文件名兜底 + 常见编码处理 |
| 大文件 / 损坏文件 | 播放失败 | 流式播放、失败跳过 |
| 浏览器自动播放限制 | 无法自动续播 | 恢复时展示"继续播放"按钮 |
| 歌词缺失或时间轴不规范 | 无法同步 | 无时间轴降级为静态展示；偏移校准放到 v1.1 |
| LRC 编码混乱（GBK / UTF-8） | 歌词乱码 | 编码探测 + GB18030 回退 |
